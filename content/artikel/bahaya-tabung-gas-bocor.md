Jumat pagi, 9 Oktober 2026, sekitar pukul 08.00 WIB — jam paling sibuk di dapur rumah makan Padang di Jl. Pegambiran, Rawamangun, Jakarta Timur. Seorang pekerja hendak mengganti tabung gas **sambil tetap memasak**. Dugaan kuat: terjadi kebocoran.

Api menyambar dalam sekejap. Pekerja sempat mencoba memadamkan dengan APAR, tapi api membesar terlalu cepat. Akibatnya: **3 orang luka bakar** (dibawa ke Puskesmas Pulogadung), atap warung bakso di sebelahnya rusak. Polisi masih melakukan olah TKP.

## Pelajaran Penting: Aturan Main Tabung Gas

Kasus ini seri terbaru dari "drama tabung gas" yang terus berulang. Catat baik-baik:

1. **Matikan kompor SEBELUM ganti tabung.** Jangan pernah ganti tabung sambil api menyala. Ini aturan nomor satu yang paling sering dilanggar.
2. **Cek karet seal & regulator** setiap ganti tabung. Kalau tercium bau gas, jangan nyalakan api — buka ventilasi, lepas regulator.
3. **APAR hanya efektif untuk api kecil.** Kalau api sudah membesar, jangan paksakan padam sendiri — **keluar, dan telepon 113.**
4. **Jangan letakkan tabung dekat sumber panas** dan pastikan ventilasi dapur baik.

Tabung gas itu aman kalau diperlakukan dengan benar — dan mematikan kalau disepelekan. Sebarkan ke grup keluarga, biar ibu-ibu dan mbak-mbak di dapur juga tahu. 🙏
