75 Rumah Hangus di Tenggarong: Pelajaran dari Satu Sore yang Kelam

14 Oktober 2026 · 2 min · DAMKARHUB
Table of Contents
  • Kenapa Api Menyebar Separah Ini?
  • Pelajaran Buat Kita

Senin sore, 5 Oktober 2026, sekitar pukul 16.30 WITA, warga Kelurahan Melayu, Tenggarong, Kalimantan Timur, melihat asap mengepul dari sebuah dapur rumah kontrakan. Dugaan awal: korsleting listrik. Masih dalam penyelidikan.

Tiga jam kemudian, lebih dari 50 rumah hangus — beberapa laporan menyebut hingga 75 unit. Kerugian materi ditaksir sekitar Rp10 miliar.

Kenapa Api Menyebar Separah Ini?#

Bukan cuma soal api besar. Ini kombinasi mematikan:

  1. Rumah kayu yang rapat — “atap ketemu atap”. Di permukiman seperti ini, satu titik api bisa meratakan satu blok dalam hitungan menit.
  2. Angin kencang musim kemarau — api lompat dari atap ke atap tanpa ampun.
  3. Gang sempit — armada damkar nggak bisa masuk ke titik api.
  4. Sumber air minim — air harus disuplai dari 1 KM jauhnya!

Damkar mengerahkan 9 armada dan 90 personel gabungan (dibantu BPBD, PDAM, polisi, relawan). Beruntung, hidran kering 1.000 meter dari Sungai Tenggarong dan 2 tandon air 5.000 liter yang sudah disiapkan pemerintah terbukti berfungsi membantu penyekatan api. Pemadaman berlangsung ±3 jam, pendinginan sampai 22.00 WITA.

Kabar baiknya: tidak ada korban jiwa — beberapa warga mengalami sesak napas dan luka ringan.

Pelajaran Buat Kita#

  • Di permukiman padat berbahan kayu, api menyebar dalam hitungan menit. Satu titik api = satu blok melayang.
  • Infrastruktur komunitas (hidran, tandon air, jalan akses) adalah pembeda antara terkendali vs katastrofe. Tenggarong selamat dari yang lebih buruk karena infrastrukturnya sudah disiapkan.
  • Ancaman terbesar menurut Kadis Damkar Kukar: “listrik dan memasak”. Cek instalasi listrik dan dapurmu sekarang.

Doa terbaik untuk warga Tenggarong. 🙏
